# Decision Log

Why decisions were made, what was rejected, and what triggered each call. Local-only. Append-only — never edit past entries; add a new entry that supersedes them.

## Entry template

```
### YYYY-MM-DD — short title

**Decision**: what was decided in one sentence.

**Why**: the reasoning. Cite wiki sources by `[[category/page]]` when applicable.

**Alternatives rejected**:
- Alternative A — rejected because …
- Alternative B — rejected because …

**Triggered by**: critique session / new data / external feedback / etc.

**Supersedes**: link to prior entry if this overrides a previous decision.
```
