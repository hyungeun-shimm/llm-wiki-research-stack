# Optional Figure Plan

This file is for `paper_in_prep` projects only. It is optional and can be created after the project brief, once the figure-level story is ready to track.

`Project_Brief.md` remains the top-level project contract. This file helps agents understand the current manuscript architecture, but it does not override the brief.

## Figure Status Values

Use one of: `planned`, `in_progress`, `data_collected`, `analyzed`, `drafted`, `complete`, `dropped`.
