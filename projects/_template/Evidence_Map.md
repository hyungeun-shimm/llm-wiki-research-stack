# Evidence Map

Mapping from draft claims to the wiki sources that support them. The Drafter writes here; the user verifies. Claims without entries are unsupported until proven otherwise.

## Format

Each row is a single claim made anywhere in `Drafts/`. The mapping is one-claim-to-many-sources.

| Claim ID | Claim (short) | Draft location | Supporting wiki pages | Supporting unpublished data | Confidence | Notes |
|---|---|---|---|---|---|---|
| C001 |  | Drafts/grant_aim1.md §2 | [[topic-a/page-a]], [[methods/page-b]] | data-updates/2026-05-ePhys | strong/moderate/weak |  |

## Claim states

- `strong` — multiple independent wiki sources directly support it
- `moderate` — one wiki source supports it, or several support it indirectly
- `weak` — only inferential or analogical support
- `unsupported` — no wiki source yet; flag for Drafter
