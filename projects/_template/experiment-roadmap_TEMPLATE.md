# Optional Experiment Roadmap

This file is for `paper_in_prep` projects when experiment planning would help. It is not mandatory, and it should not create fake urgency for experiments that are not actually needed.

`Project_Brief.md` remains the top-level project contract. This roadmap is a live planning aid.

## Experiment Status Values

Use one of: `not_needed`, `planned`, `in_progress`, `data_collected`, `analyzed`, `complete`, `dropped`.
