# Mendeley Review

Generated Mendeley audit reports are written here.

This folder is private and ignored by git except for this README. The reports are meant to help you:

- See what is in the current Mendeley library.
- Propose a cleaner topic taxonomy.
- Find duplicate or metadata-poor references.
- Pick a small, high-value subset to ingest into the LLM-Wiki.

The audit does not modify Mendeley, rename PDFs, or import anything into the wiki.
