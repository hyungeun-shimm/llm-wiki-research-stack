# Tool Routing Quick Reference

| If you want to... | Use |
|---|---|
| Find papers, score candidates, ingest PDFs | Codex CLI |
| Write or revise a draft | Claude Code |
| Build or update overview pages | Claude Code |
| Pressure-test a paper-in-prep figure/data plan | Claude Code |
| Run `scripts/verify_citations.py` or any other script | Codex CLI |
| Decide if your hypothesis is sharp enough | Claude Code |
| Bulk-rename files, fix frontmatter, or refactor local files | Codex CLI |
| Ask a one-off conceptual question that does not touch files | Claude Code |

Switching tools means changing into this same folder and launching the other tool. The filesystem is the shared state.
